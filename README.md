# LEO GOLD — Premium Catalog

## Встановлення на GitHub Pages
1. Завантажте ВСІ файли та папку `assets` у корінь репозиторію (не вкладайте папку `leo-gold-catalog` всередину іншої папки).
2. У GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. Відкрийте сайт і зробіть жорстке оновлення: Mac `Cmd + Shift + R`, Windows `Ctrl + Shift + R`.

## Додавання товарів
Редагуйте тільки `products.js`. У кожного товару має бути унікальний `id`. Фотографії кладіть у `assets/` і вказуйте точний шлях.

## Instagram
У `products.js` змініть `INSTAGRAM_USERNAME` на назву акаунта без `@`.

Каталог не оформлює замовлень; кнопка товару відкриває Instagram Direct.
